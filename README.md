# Rock Paper Scissors

A simple Rock Paper Scissors game made with Python.

## Features

* Player vs computer
* Random computer choices
* Score system
* Draw counter
* Replay system
* Input validation

## Technologies

* Python
* Random module

## How to Play

Run `Rock_Paper_Scissors_VERSAO_FINALIZADA` and choose:

1. Rock
2. Paper
3. Scissors

The computer will randomly choose an option.

## Project

This project was created as a personal Python programming project to practice conditionals, loops, variables, random numbers, and game logic.
